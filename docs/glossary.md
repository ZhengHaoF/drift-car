# 词汇表

| 术语 | 英文 | 定义 |
|------|------|------|
| 之字路 | Zigzag Road | 由 45°/135° 两种方向的直路段交替拼接而成的无尽赛道 |
| 路段 | Segment | 一段固定方向的直路，路面生成的基本单位 |
| 转折 | Bend | 两个不同方向路段的连接点，玩家需在此处切换方向 |
| 切换 | Switch | 玩家单击后，车头在 45°↔135° 之间的转换动作 |
| 漂移弧线 | Drift Arc | 切换时车走过的圆弧过渡轨迹（固定角速度，半径随速度增大） |
| 漂移打断 | Drift Interrupt | 漂移弧线进行中再次点击 → 立即从当前实际朝向开启反向弧线 [ADR-0006] |
| 侧滑角 | Slide Angle | 车头朝向与实际运动方向的夹角；假侧滑模型中速度方向滞后追赶车头形成甩尾 [ADR-0013] |
| 坠落 | Fall | 车中心点出界后的死亡表现：下坠 + 旋转 + 缩小 ~0.8s，相机停住，随后弹结算 [ADR-0010] |
| 45°/135° | — | 车行进方向相对屏幕竖直轴的夹角；世界中为对角方向（相机固定不旋转，故屏幕上恒呈现此二角） |
| 出界 | Off-road | 车离开路面 → 触发坠落失败（判定细节待定，见决策树 Q14） |
| 中心线 | Centerline | 路段中线；金币默认排布参考线 |
| 米数 | Distance | 无尽模式主分，单位米 |
| 胎印 | Tire Marks | 漂移时在路面上留下的黑色痕迹（随时间淡出或永久保留，待定） |
| 烟雾 | Smoke | 漂移时车尾的粒子特效 |
| 色块风 | Flat-color Style | 复刻广告的视觉风格：纯色底（橙/黄）+ 纯色路面（灰/绿），无纹理贴图 |
