# 设计决策树

根：手机网页漂移赛车游戏（参考"这车开着不烧心"广告；两个行进方向 45°/135°，切换时漂移）

## 已敲定（设计层全部）

- 操作模型 → 单击任意位置切换 45°↔135° [ADR-0001]
- 漂移手感 → 圆弧过渡（固定角速度，半径随速度增大）[ADR-0001]
- 漂移中再点 → 可打断反向，从当前实际朝向开启新弧线 [ADR-0006]
- 速度模型 → 随距离加速，死亡重置 [ADR-0002]
- 视觉 → Three.js 真 3D，色块风 [ADR-0004]
- 相机 → 透视相机俯角 ~60°，固定不旋转、跟随车 [ADR-0009]
- 车模型 → 程序化低多边形拼装车（蓝色主色，零外部资源）[ADR-0009]
- 关卡结构 → 无尽模式，距离即分数 [ADR-0003]
- 路面生成 → V 形折弯 + 段长随机收窄 + 连续同向 ≤2 [ADR-0007]
- 金币 → 沿中心线成串，转折处沿弧线排布 [ADR-0008]
- 失败条件 → v1 仅冲出路面即死，无障碍物 [ADR-0003]
- 出界判定 → 车中心点离开路面即触发 [ADR-0010]
- 坠落表现 → 下坠 + 旋转 + 缩小 ~0.8s，相机停住后弹结算 [ADR-0010]
- 计分 → 距离主分 + 金币收集 + localStorage [ADR-0003]
- 流程 → 极简流（开始页→游戏→坠落→结算→点击重开），无复活，首局提示 [ADR-0011]
- 技术栈 → Vite + TypeScript + Three.js [ADR-0004]
- 音频 → 基础音效（胎噪/金币/坠毁），首次手势解锁，无 BGM [ADR-0005]
- 实现修正 → 弯道斜接补片渲染（判定保持方帽）、坠落深渊表现、车尾特效锚点 [ADR-0012]
- 漂移手感 → 假侧滑模型（速度方向滞后追赶车头）+ 车体缩放 0.72 + 车轮 YXZ 旋转层级 [ADR-0013]
- 自由拖拽模式 → 动态虚拟摇杆 + 抓地力漂移（侧向需求超限自动甩尾）+ 曲率路带赛道（S 弯/150° 回头弯/螺旋）+ 模式选择架构 [ADR-0014]
- 默认 → 界面文案中文

## 实现期默认参数（集中调参配置，不逐项决策）

- 初速 / 加速度曲线 / 角速度 / 速度上限
- 路宽、段长上下限与收窄速率
- 金币拾取半径、胎印保留时长、烟雾粒子数量
- 颜色主题（橙底灰路起步，远距离切换黄底绿路）
- 像素比上限（低端机性能预算）、坠落时长
- 竖屏优先；页面不可见时自动暂停；桌面端鼠标点击/空格键可玩（便于开发调试）

- 诱惑支线金币（风险换收益）
- 皮肤/升级系统、复活机制、BGM、音量开关
