# ADR-0006: 漂移中再次点击 = 可打断反向

日期: 2026-11-07
状态: 已接受

## 背景

ADR-0001 定了圆弧过渡手感后，弧线进行中（尚未甩到位）再次点击的行为成为手感核心分歧点。

## 决策

**可打断反向**：漂移弧线中途点击 → 立即从**当前实际朝向**开启反向弧线（旧弧线被新弧线替代，不是从上一次目标朝向续接）。

## 否决方案

- **漂移锁定**（转完才可再点）：规则简单但不够灵活。
- **输入缓冲**（记住点击、转完执行）：v1 不需要，试玩后觉得手感不足可小成本升级。

## 后果

- 高手可以中途反向微调走位，技巧上限更高。
- 快速连点会蛇形横跳——这是玩家自己选择造成的风险，属于技巧/惩罚设计的一部分，不做额外限制。
- 实现注意：打断以车的实际朝向为起点，避免朝向瞬移。
