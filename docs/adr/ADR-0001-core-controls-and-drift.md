# ADR-0001: 核心操作与漂移手感

日期: 2026-11-07
状态: 已接受

## 背景

游戏核心循环是：车自动行驶，玩家在赛道转折处切换车头方向，切换时以"漂移"姿态转弯。需要确定触发方式与转向手感模型，这是整个游戏手感的基础。

## 决策

1. **操作模型**：单击屏幕任意位置，车头在 45° ↔ 135° 之间切换（toggle 模型）。
2. **漂移手感**：切换通过**圆弧过渡**完成——车以固定角速度从当前朝向甩到新朝向（约 0.2~0.4s 到位），速度越快弧线半径越大；弧线期间留下胎印 + 烟雾特效。

## 否决方案

- **瞬间转向**：漂移只是装饰特效，没有"漂移"的体感。
- **惯性物理模拟**（速度矢量与车头分离、真实侧滑）：太硬核，休闲玩家难以预期车的行为，调参成本高。
- **按住转向**（Drift Boss 式）与**分区点击**：与"就两个方向，切换时漂移"的需求不符。

## 后果

- 弧线既是代价（切早了会甩出路面）也是技巧空间（贴弯心切走最短线）。
- 角速度、弧线半径参数需真机调参（Q3 的速度曲线直接影响半径）。
- "漂移弧线进行中再次点击"的行为待后续 ADR 定义。
