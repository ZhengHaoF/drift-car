# ADR-0003: 游戏结构与计分

日期: 2026-11-07
状态: 已接受

## 背景

参考广告中的米数计分（38m / 480m）与路面形态，需确定游戏整体结构。

## 决策

1. **无尽模式**：程序生成"之字路"，距离（米）即主分。
2. **失败条件（v1）**：仅"冲出路面"——车离开路面即失败；v1 无障碍物。
3. **计分**：距离为主分，金币散布在路上可收集；最高分与金币累计存 localStorage。
4. 界面文案默认**中文**。

## 否决方案

- **固定关卡制**：需关卡设计成本，与无尽米数计分的广告形态不符。
- **障碍物碰撞失败**（v1）：等核心手感打磨好再加，作为内容扩展。
- **出界宽容**（减速挣扎）：规则不清晰，v1 不做。

## 后果

- 路面生成规则（转折结构、段长分布、同向限制）待后续 ADR 定义。
- 金币布局方式待定（中心线 vs 诱惑支线）。
- 皮肤/升级系统不在 v1 范围。
