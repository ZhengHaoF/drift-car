# ADR-0002: 速度与难度曲线

日期: 2026-11-07
状态: 已接受

## 背景

参考广告文案"速度快了转弯就不行了？"——速度是这类游戏的核心难度来源。需确定车速随时间如何变化。

## 决策

车速**随行驶距离缓慢提升**，死亡后重置为初始速度。起步较慢、易于上手；随距离增加，漂移弧线半径随速度增大，同样的切换时机越来越难。

## 否决方案

- **恒定速度**：难度只能靠路形变化，曲线单调。
- **加速带/减速带局部变速**（v1）：内容成本高，留作后续扩展。

## 后果

- 速度与弧线半径的耦合关系需在物理调参时一起定（见 [[ADR-0001-core-controls-and-drift]]）。
- 需要设定初速、加速度曲线、速度上限三个参数。
