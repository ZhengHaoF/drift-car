# ADR-0007: 路面生成规则

日期: 2026-11-07
状态: 已接受

## 背景

ADR-0003 定了无尽模式后，之字路的程序生成需要具体规则。

## 决策

1. **转折结构**：V 形折弯——两段不同方向的直路段直接相接于一点（如广告图），无圆弧弯道段；车的漂移弧线自然圆过拐角。
2. **段长**：随机分布，随机范围随距离**收窄**——转折越来越密，与速度曲线（ADR-0002）叠加构成双重难度来源。
3. **同向限制**：连续同向转折 ≤ 2 次，防止路线绕圈自交。

## 否决方案

- **圆弧弯道段**：视觉圆润，但与车的漂移弧线叠加后走位判定复杂。
- **严格左右交替**：节奏可预测，玩久会腻。

## 后果

- 生成器只需维护"当前方向 + 下一转折点"，状态极简。
- 段长上下限、收窄速率为实现期调参（集中配置）。
