# ADR-0012: 实现期修正——弯道斜接渲染、坠落深渊表现、车尾特效

日期: 2026-11-07
状态: 已接受

## 背景

首版实现经无头浏览器截图验收，发现三处与设计意图不符的表现问题。

## 决策

1. **弯道渲染改为斜接补片**：路段网格不再两端延伸半宽（方帽），转折处放置一个三角形补片（顶点 = 转折点、转折点 ± 半宽×(两段转弯侧法线之和)），拼出广告同款的干净斜接角，消除方帽并集在弯道产生的 V 形缺口。
2. **碰撞判定保持方帽并集**：出界判定继续用车中心点对方帽延伸路段并集（ADR-0010）。转折处判定区域略宽于视觉斜接边缘 → 弯道判定天然宽容，符合"中心点判定自带半个车宽容度"的原则。
3. **坠落表现改为"坠入深渊"**：原方案车下坠会没入地面网格被遮挡而瞬间消失；改为地板同步坠走，车在背景色深渊中翻滚缩小，结算态保持坠落终态（相机停住不变）。
4. **特效锚定车尾**：胎印从两后轮、烟雾从车尾生成（初版误锚定车头）。

## 后果

- 弯道外侧视觉边缘与判定边缘存在约半宽级的差异（判定更宽容），属有意选择。
- 胎印弧线与漂移弧线重合，视觉反馈与实际轨迹一致。
