# ADR-0010: 出界判定与坠落表现

日期: 2026-11-07
状态: 已接受

## 背景

ADR-0003 定了"冲出路面即死"后，需要确定判定的宽容度与死亡的表现形式。

## 决策

1. **判定**：车**中心点**离开路面即触发（天然自带半个车宽的宽容度）。
2. **表现**：触发后车坠落（下坠 + 旋转 + 缩小消失，约 0.8s），相机停住看着车掉下去，随后弹结算浮层。

## 否决方案

- **车身完全离开才判定**：更宽容但视觉上"车悬空一半才死"，观感怪。
- **无动画直接结算**：缺少"死得心服口服"的反馈。

## 后果

- 判定只需车中心点与当前/相邻路段的位置关系，计算极简。
- 坠落期间输入无效；坠落时长为实现期调参。
