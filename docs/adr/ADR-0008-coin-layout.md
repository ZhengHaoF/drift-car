# ADR-0008: 金币布局

日期: 2026-11-07
状态: 已接受

## 背景

ADR-0003 定了金币收集后，需要确定金币在路上的分布方式。

## 决策

金币**沿路段中心线成串排布**；转折处沿车的漂移弧线路径排布（贴合实际走线）。顺路走基本全收——金币是正反馈，不是考验。

## 否决方案

- **诱惑支线**（金币放偏离最优线的位置，风险换收益）：v2 调味料，与障碍物一起作"进阶内容包"。
- **随机散布**：显得脏乱，无节奏感。

## 后果

- 拾取半径与车宽挂钩（实现期调参）。
- 金币为纯收集计数（存 localStorage），v1 不挂任何消耗系统。
