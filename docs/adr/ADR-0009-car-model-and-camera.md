# ADR-0009: 车模型与相机

日期: 2026-11-07
状态: 已接受

## 背景

ADR-0004 定了 Three.js 真 3D 后，需要确定车的模型来源与相机的具体形态。

## 决策

1. **车模型**：程序化低多边形拼装车——盒子组合车身/车顶/四轮，蓝色主色，零外部资源、加载零等待。
2. **相机**：透视相机，俯角约 60°，**固定不旋转、跟随车**（路面在屏幕上始终呈斜向色块，如广告）。

## 否决方案

- **glTF 外部模型**：观感上限更高（更接近广告甲壳虫车），但引入资源寻找 + 加载管理；架构上留好车模型接口，以后可换。
- **正交相机**：纯俯视工程图感，缺广告的"近大远小"。

## 后果

- 渲染层需将车抽象为可替换接口（v1 用拼装车实现）。
- 俯角与跟随距离为实现期调参。
