# ADR-0011: 流程与新手引导

日期: 2026-11-07
状态: 已接受

## 背景

一局时长短（预期 30 秒内），需要零摩擦的死亡-重开循环；手机网页音频需手势解锁（ADR-0005）。

## 决策

**极简流**：
1. 开始页：标题 + 最高分 + "点击开始"
2. 点击即开始游戏，**同时解锁 AudioContext**（与 ADR-0005 合并处理）
3. 死亡 → 坠落动画（ADR-0010）→ 结算浮层：本次距离 / 金币 / 最高分 + 新纪录标记
4. 点击任意处立即重开
5. **无复活机制**
6. 新手提示：仅首局，在第一个转折前浮现"点击！"提示箭头，之后不再出现

## 否决方案

- **免费复活一次**：复刻广告钩子但无广告价值支撑，等有留存数据再说。
- **3-2-1 倒计时开场**：增加重开摩擦，与零摩擦循环矛盾。

## 后果

- 提示出现逻辑：localStorage 标记"已玩过一局"。
- 结算浮层需展示金币累计（ADR-0008）。
