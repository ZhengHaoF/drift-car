# ADR-0014: 自由拖拽模式（连续转向 + 抓地力漂移 + 曲率路带）

日期: 2026-11-13
状态: 已接受

## 背景

v1 的"单击切换"手感验证后，需要第二种驾驶范式：手指拖动连续控向，转向过猛自动触发漂移；赛道升级为圆滑弯道（S 弯 / 回头弯 / 螺旋）。经典模式冻结不动。

## 决策

1. **操控映射——动态虚拟摇杆**：按住屏幕任意位置 = 摇杆原点，拖动**方向** = 目标朝向，拖动**幅度**（原点满幅 90px）线性缩放目标朝向角（模拟量：微拖=微转，拖满=满舵）；拖出满幅后原点浮动跟随（摇杆不脱手）。松手保持当前朝向直行。目标朝向钳制在**屏幕正上 ±75°**（保证车永远向上前进——路面生成、相机、旧路段清理全部依赖此约束）。桌面端鼠标拖拽同逻辑，方向键备用微调。

2. **抓地力漂移模型（连续，无二值状态机）**：车头以 `yawChaseK`（4.5）比例追赶目标朝向、角速度上限 `maxYawRate`（3.2）；**侧向需求 a = |车头角速度| × 车速**，抓地系数 grip 在 `gripALow`(18) ~ `gripAHigh`(26) 间饱和下降；速度方向追赶车头的速率 = lerp(漂移追赶 6, 抓地追赶 16, grip)。侧滑角超过 0.14 进入漂移特效、低于 0.08 退出（滞回防闪烁）。效果：低速缓拖=干净切弯，急甩/高速过弯=自动甩尾——"速度快了转弯就不行"由物理量自然涌现。**漂移掉速**：满侧滑时速度 ×0.65（`driftScrub` 0.35，可配置）。

3. **赛道——连续曲率积分路带**（对"自由样条"诉求的安全实现）：路段 = 直段/弯道片段（弯道 = 缓入-定曲率-缓出梯形曲率 profile），按 2m 步长积分出中心线，弯道参数（角度 35°~150°、峰值曲率 0.03~0.11、直段长度）随距离收窄加压；累计朝向 ±75° 预算（超半强制回摆）；**片段铺设前整体模拟并做前瞻自交检测**（SAT，撞了重掷片段）。渲染为密集四边形路带（顶面 + 两侧壁，顶点色携带主题），判定为路带四边形并集（z 单调窗口 + 凸四边形测试）。金币沿中心线等距。

4. **模式架构**：开始页两张模式卡（经典挑战 / 自由拖拽）进入对应模式；`Game` 持有 `IRoadGen` 接口双实例（经典 RoadGen 冻结不动 / SplineRoadGen 新增）；最高分、首局标记按模式分键（`drift.best.classic|drag`），金币累计共用；结算页新增"换模式"返回入口；新手提示按模式出文案（"点击！" / "按住拖动！"）。

5. **手感细节**：前轮 counter-steer（漂移时前轮朝速度方向反向修正）；胎印透明度、烟雾、胎噪音量与音高随侧滑角连续变化（经典模式音量保持原布尔行为）；拖拽模式相机视线沿实际运动方向前引；进弯安卓振动反馈（`navigator.vibrate` 30ms，纯 juice）。

## 否决方案

- **指哪打哪绝对朝向**：手指通常在车下方，映射别扭，且没有"转向力度"模拟量。
- **全 360° 朝向 / 真 180° 掉头**：破坏"车永远向上前进"假设，生成/相机/清理需推倒重来（Q7=A）。
- **分段相机旋转**：观感最佳但等于重做相机系统，留 v2。
- **Catmull-Rom 控制点样条拟合**：易打环/自交/超预算，曲率积分法观感相同且每步可校验。
- **二值漂移状态机**：进出漂移会抖，连续 grip 更顺。

## 后果

- 漂移手感三主旋钮：`gripALow/gripAHigh`（漂移触发线）、`yawChaseK/maxYawRate`（转向重量）、`driftCatchRate`（甩尾幅度）；真机调参是后续主要工作。
- 路带缓冲环形复用（2048 段 ≈ 4km），超出后最旧路段被覆盖——远在相机视野外，无视觉影响。
- 经典模式代码路径零改动（仅金币挂载方式重构为共享方法，行为等价），冒烟测试守护。
- **实现约束（试玩期验证所得）**：① 片段交界角点必须"每点只算一次"并跨片段传递——`buildQuads` 必须是纯函数（曾因重试循环污染交界角点产生楔形缝，车沿中心线行驶也判出界）；② 出界判定必须全量扫描活动路段——大侧向角（>40°）时角点 z 散布远大于每段 z 步长，任何二分窗口法都会漏掉包含车的路段；判定含 0.15m 贴边宽容。
- 自动化守护：`scripts/auto-drive.mjs` 页面内 rAF 级自动驾驶长跑（无坠落、无 NaN、无报错为通过线）。
